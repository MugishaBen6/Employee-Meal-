# API Documentation - Employee Meal Management System

Base URL: `http://localhost:8080/api`

## Authentication

### 1. Login
- **Endpoint**: `POST /auth/login`
- **Access**: Public
- **Request Body**:
```json
{
  "usernameOrEmail": "admin",
  "password": "Password123!"
}
```
- **Response**:
```json
{
  "success": true,
  "message": "Login successful",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "type": "Bearer",
    "user": {
      "id": 1,
      "username": "admin",
      "email": "admin@company.com",
      "firstName": "System",
      "lastName": "Admin",
      "role": "ADMIN"
    }
  }
}
```

## Employees

### 2. Search & List Employees
- **Endpoint**: `GET /employees?query=&department=&status=&page=0&size=10`
- **Access**: ADMIN, MANAGING_DIRECTOR, ACCOUNTANT, HR

### 3. Quick Search Employees
- **Endpoint**: `GET /employees/quick-search?query=EMP001`
- **Access**: ADMIN, MANAGING_DIRECTOR, ACCOUNTANT, HR

### 4. Create Employee
- **Endpoint**: `POST /employees`
- **Access**: ADMIN, HR
- **Request Body**:
```json
{
  "employeeCode": "EMP009",
  "firstName": "Moses",
  "lastName": "Mutangana",
  "department": "Production",
  "position": "Operator",
  "phone": "+250788100009",
  "email": "moses@company.com"
}
```

### 5. Update Employee
- **Endpoint**: `PUT /employees/{id}`
- **Access**: ADMIN, HR

### 6. Deactivate Employee
- **Endpoint**: `DELETE /employees/{id}`
- **Access**: ADMIN, HR

---

## Meal Records

### 7. Record Employee Meal
- **Endpoint**: `POST /meals`
- **Access**: ADMIN, HR
- **Request Body**:
```json
{
  "employeeId": 1,
  "mealDate": "2026-08-26",
  "mealStatus": "ATE",
  "amount": 1500.00
}
```
- **Error Response (Duplicate Meal Prevention)**:
```json
{
  "success": false,
  "message": "Meal already recorded for this employee today."
}
```

### 8. Quick Meal Check
- **Endpoint**: `GET /meals/quick-check?query=EMP001&date=2026-08-26`
- **Access**: ADMIN, MANAGING_DIRECTOR, ACCOUNTANT, HR

---

## Reports & Downloads

### 9. Get Daily Meal Report Data
- **Endpoint**: `GET /reports/daily?date=2026-08-26&department=`
- **Access**: ADMIN, MANAGING_DIRECTOR, ACCOUNTANT, HR

### 10. Download Daily Excel Report
- **Endpoint**: `GET /reports/daily/excel?date=2026-08-26`
- **Access**: ADMIN, MANAGING_DIRECTOR, ACCOUNTANT, HR
- **Format**: `.xlsx` stream generated by Apache POI

### 11. Download Daily PDF Report
- **Endpoint**: `GET /reports/daily/pdf?date=2026-08-26`
- **Access**: ADMIN, MANAGING_DIRECTOR, ACCOUNTANT, HR
- **Format**: `.pdf` stream generated by OpenPDF
